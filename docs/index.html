Engine Architecture

Modular subsystems cleanly decoupled for embeddability and maximum concurrency.

🔷

Core Variant System

Dynamic container supporting all 35 Godot 4 variant types with complete operator overloading, conversions, arithmetic, Callable method references, and Signal event bindings.

Variant Callable Signal StringName NodePath
📐

Spatial 2D & 3D Math

Zero-allocation vector, matrix, and geometric transformations matching Godot's C++ math library 1:1, including basis orthonormalization, Euler decomposition, and spherical interpolation.

Vector2/3/4 Transform2D/3D Basis Quaternion Rect2/AABB
🌲

SceneTree & Node Hierarchy

Hierarchical scene graph with node lifecycle hooks (enter_tree, ready, step, physics_step), groups, pause processing modes, and relative/absolute node path queries.

SceneTree Node2D Node3D CharacterBody Control UI
⚙️

Subsystem Servers

Low-level concurrent server architecture handling draw commands (RenderingServer), AABB and raycast queries (PhysicsServer2D), audio buses (AudioServer), and action maps (Input).

RenderingServer PhysicsServer2D AudioServer Input
📜

Godot 4 .tscn Parser

Native lexer and parser for Godot's text scene format. Directly parses .tscn files into a PackedScene resource and instantiates live node subtrees into the active SceneTree.

TscnParser TscnSerializer PackedScene project.godot
🔍

ClassDB Reflection

Global runtime class registry providing type introspection, inheritance verification, property bindings, and node instantiation factories without runtime overhead.

ClassDb GodotObject ObjectId Notifications

Quick Start

Use Godot-RS as a Rust library or standalone command line tool.

1. Library Usage (Cargo.toml)

[dependencies]
godot = { package = "godot-rs", version = "0.1.0" }

2. Rust Code Example

use godot::prelude::*;

fn main() {
    // 1. Initialize engine reflection and servers
    ClassDb::init();
    init_servers();

    // 2. Create SceneTree and root nodes
    let mut tree = SceneTree::new();
    let root = tree.get_root();

    // 3. Build a player character body node
    let mut player = Node::new("Player", "CharacterBody2D");
    player.set_property("position", Variant::Vector2(Vector2::new(100.0, 200.0)));
    player.set_property("velocity", Variant::Vector2(Vector2::new(150.0, 0.0)));
    player.add_to_group("players");

    let player_id = tree.add_node(player);
    tree.add_child(root, player_id);

    // 4. Step physics simulation (60 Hz)
    tree.physics_step(1.0 / 60.0);

    let player_ref = tree.get_node(player_id).unwrap();
    println!("Player updated pos: {:?}", player_ref.get_property("position"));
}

3. CLI Commands

# Install CLI binary
cargo install --path .

# Scaffold a new Godot project
godot new MyGame

# Run simulation loop on a .tscn scene file
godot run MyGame/main.tscn --ticks 120

# Parse and inspect AST of a .tscn file
godot parse MyGame/main.tscn
